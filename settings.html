As an Administrator, you have the following permissions:

  • ✓ Create, edit, and manage other admin accounts
  • ✓ Reset passwords for fellow administrators
  • ✓ Manage supervisor accounts
  • ✓ Manage data collectors
  • ✓ Manage districts
  • ✓ Export data for backup

For security and audit purposes, regular administrators cannot:

  • ✗ Clear activity logs
  • ✗ Import data
  • ✗ Delete system data
  • ✗ Reset the entire system

To view activity logs, please go to the Reports page.
